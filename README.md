# Agent Resource Browser

一个无需安装依赖的中文 Agent 开发资料检索页。按关键词、厂商和主题筛选公开链接，适合本地查资料或维护自己的学习索引。

![Agent 资料库实际运行界面，展示精选入口与筛选栏](docs/images/browser.png)

上图为本仓库实际运行截图，显示内置链接快照。

## 用途与亮点

- 内置 **1,162 条公开链接、62 个精选入口**，快照日期为 **2026-10-26**。覆盖 OpenAI、Anthropic 相关站点及 MCP、Agent Skills 标准入口。
- 支持大小写无关的多关键词搜索；多个词需同时匹配。可组合厂商、主题和精选筛选，每次展示最多 80 条，按需加载更多。
- 页面、样式、脚本和数据均在仓库内；搜索无需联网，无统计脚本、账号或服务端。打开原文链接时才访问外部网站。
- JSON 是数据源，构建脚本生成可直接用 `file://` 打开的数据文件，并校验链接来源、重复项和字段。

## 前置条件与运行

阅读只需支持现代 JavaScript 的桌面或手机浏览器。下载完整仓库并解压，直接打开 `index.html`。不要仅下载这一份 HTML。

可选：若本机已有 Python 3，可在仓库目录运行：

```sh
python -m http.server 8000 --bind 127.0.0.1
```

然后打开 `http://127.0.0.1:8000`。通过 HTTP 打开时，“下载 JSON 索引”会保存文件；部分浏览器直接打开本地文件时会展示 JSON，可另存为。

维护和验证需要 **Node.js 20 或更新版本**，没有 npm 依赖，无需运行 `npm install`。

## 维护自己的索引

编辑 `data/resources.json`，再执行：

```sh
npm run build
npm run check
npm test
```

每条资料包含 `vendor`、`group`、`topic`、`kind`、`title`、`url`、`priority`。`priority: 0` 表示普通条目，正整数越小越靠前；`snapshot_date` 表示数据整理日期。主题选项会由数据自动生成。

`core.js` 限制为列出的 HTTPS 公开站点，GitHub 链接限 `openai` 和 `anthropics` 组织；不接受凭据、查询参数、片段和非默认端口。增加新来源需要明确修改白名单并更新测试，不能只替换域名绕过校验。下载 JSON 与离线数据应一起提交；`npm run check` 能发现二者不同步。

## 目录结构

```text
index.html                 页面与筛选控件
styles.css                 响应式样式
app.js                     安全 DOM 渲染和交互
core.js                    数据校验与搜索
data/resources.json        可编辑、可下载的链接索引
data/resources.js          由构建脚本生成的离线数据
scripts/build.cjs          数据构建和一致性检查
tests/core.test.cjs        数据、边界和搜索测试
docs/images/browser.png   实际运行截图
```

## 验证方式

运行上述三条命令，测试覆盖来源白名单、重复数据、无效字段、危险 URL、多词组合筛选、排序及离线数据一致性。另可执行 `node --check app.js` 和 `node --check core.js` 检查语法。

浏览器手动验收：默认展示 62 个精选入口；点击“查看全部资料”展示首批 80 条，再点“显示更多”；组合搜索、厂商和主题；输入不存在的词应显示空状态；“重置筛选”应恢复默认。缩窄窗口检查单列布局与横向溢出。

## 已知限制

这是历史链接快照，不是实时搜索引擎。没有逐条重新访问全部链接，来源网页可能迁移、下线或改变权限；产品生命周期与接口状态应在原站确认。索引只提供标题与分类，不保证中文搜索能匹配英文标题，也不包含全文搜索。文档章节、代码目录和课程入口的粒度不同，数量不能视为文章数量。

分类与精选顺序是整理时的判断，并非厂商背书。页面不提供直接编辑、同步或自动抓取；维护者需修改 JSON 后重新构建。白名单限定了当前来源范围，尚不支持任意链接导入。
